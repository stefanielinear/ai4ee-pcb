# Rev B 3D previews

Generated from the saved Rev B PCB using the native KiCad renderer. 110 package models: 107 standard KiCad models and three visual approximations (U2 module, J2 USB-C, U3 generic QFN). Fourteen test pads and six fiducials have no physical package. Model coverage and source hash are in model_coverage.json. Use manufacturer drawings for mechanical approval.

ECG12_Portable2.kicad_pcb in this directory is a render copy; edit the project-root PCB for design work. Models resolve locally through the models directory.

# ai4ee-pcb

[简体中文](README.zh-CN.md)

A collection of PCB projects that are automatically designed and generated by AI.

All projects are designed in **KiCad**. This repository hosts PCB projects produced by an AI agent (LLM toolchain) end to end — from requirements specification and part selection, through schematic entry, layout and routing, design review, to fabrication file export. Each sub-project lives in its own directory and can be opened directly in KiCad; it ships with the design sources, design documentation, and a fabrication package.

## Sub-projects

| Sub-project | Description | Status | Model / tokens |
| --- | --- | --- | --- |
| [ECG12_Portable](ECG12_Portable/README.md) | Portable 12-lead ECG acquisition board (engineering sample): KiCad 10, 45 × 45 mm 4-layer board, 110 purchased components, 14 test points, 6 double-sided fiducials, Rev B | Routed (native ERC / DRC: 0 violations, 0 unconnected), prototype validation pending | GPT-6 High, ~580k tokens |
